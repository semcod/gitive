# Szablon projektu

- `gitive.project.json`: powiązanie repo z workspace, testami i polityką wykonawcy.
- `src/`: kod aplikacji.
- `tests/`: testy i kryteria odbioru.
- `docs/`: dokumentacja projektu.
- `project/`: tickety i ich metadane; kod wykonawczy pozostaje w src/tests.

To wzorzec struktury, nie gotowa aplikacja i nie aktywny ticket. Dostosuj komendy
testowe do stosu projektu. Nie zastępuj istniejącej struktury importowanego repo.
