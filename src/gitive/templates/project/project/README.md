# Dokumentacja zadań

Aktywne tickety i ich synchronizacja należą do `semcod/planfile` w `.planfile/`
tego projektu. Nie twórz tu konkurencyjnego rejestru ani własnego alokatora.
Istniejące dokumenty governance repo zachowaj; nie zastępują one natywnego
identyfikatora i powiązania Issue zapisanego przez Planfile.
